# Tetra Releases

Public, prebuilt Tetra CLI binaries and checksums for macOS, Linux, and Windows.

- [Download the latest release](https://github.com/solidpixels-inc/tetra-releases/releases/latest)
- macOS: `brew install solidpixels-inc/solidpixels/tetra`
- Product: [Solidpixels Tetra](https://solidpixels.io/products/tetra/)

The source repository is private; this repository contains release artifacts only.
